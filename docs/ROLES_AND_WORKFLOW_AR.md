# الأدوار ومسؤولية التحديث

## المالك / العضو
يحدث:
- التزامه الأسبوعي.
- الأدلة.
- العوائق.

لا يستطيع:
- اعتماد إنجازه بنفسه.
- تسجيل تدخل سكرتير.
- تعديل عمل شخص آخر.

## السكرتير
يستطيع داخل سكرتاريته:
- رؤية الخطة والنتائج والمحطات.
- إضافة Intervention عند ظهور عائق أو انحراف.
- التحقق من Milestone أو إعادتها للمالك.
- إدارة Proposal قبل رفعه للسكرتارية العامة.
- متابعة تنفيذ المقترحات المجازة.

## السكرتارية العامة
تستطيع:
- رؤية الصورة الكلية.
- مقارنة أداء السكرتاريات.
- إضافة Oversight Note موجهة للسكرتارية.
- اتخاذ القرار النهائي في المقترحات.

لا تستخدم النظام لتنفيذ تدخل مباشر بدل السكرتير، ولا لاعتماد Milestone نيابة عنه.

## Admin
مسؤول عن:
- المستخدمين والأدوار.
- السكرتاريات.
- الدورة الحالية.
- إعدادات SLA.
- البنية التقنية.
